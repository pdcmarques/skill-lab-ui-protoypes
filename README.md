# Skills Lab UI Prototypes

Disposable, browser-testable UI prototypes for the Skills Lab design process.

These prototypes are visual and interaction references, not production application code.

## Current prototypes

- **Precise Curiosity — Exercise Canvas**: canonical exercise-shell exploration with a fixed viewport composition, explicit equal-groups/table diagram, multiple mathematical representations, feedback, hints and a mini-lesson.

## Design workflow

1. Explore a visual direction.
2. Build a browser-testable prototype with real learning content.
3. Review on desktop, tablet and phone.
4. Iterate on composition and interaction.
5. Promote mature prototypes to normative design exemplars for the production Skills Lab implementation.

## GitHub Pages

The repository is intentionally static and can be served directly by GitHub Pages from the `main` branch and repository root.
