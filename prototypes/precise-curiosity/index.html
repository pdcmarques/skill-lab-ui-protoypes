1 GUIDED MINI LESSON

From equal groups to multiplication

1 · Identify one group

Each table has 4 children. That number stays the same in every group.

2 · Count the groups

There are 6 tables, so we have six equal groups of four.

3 · Connect the representation

Six groups of four can be written as 6 × 4. You can now return and find the total.
